Package layout
==============

``lace.cosmo``
   CAMB-backed cosmology classes, linear-power utilities, and rescaling.

``lace.archive``
   Base archive behavior and Gadget/Nyx simulation archives.

``lace.emulator``
   Gaussian-process and neural-network emulators, training selection, and
   emulator covariance tools.

``lace.utils``
   Shared numerical, smoothing, fitting, and plotting utilities.
