Package layout
==============

``lace.cosmo``
   CAMB-backed cosmology classes, linear-power utilities, rescaling, and the
   named cosmologies (Planck fiducials and simulation suites).

``lace.archive``
   Base archive behavior and Gadget/Nyx simulation archives
   (``_gadget_io`` reads MP-Gadget/GenIC parameter files).

``lace.emulator``
   Gaussian-process emulators, P1D smoothing (``poly_p1d``,
   ``smoothing_manager``), model manifests, and emulator covariance tools.

``lace.plotting``
   Archive, emulator, and covariance figures; ``lace.plotting.style`` holds the
   house style.

``lace.utils``
   Shared helpers (chains, parameter-name and repository-path utilities).
