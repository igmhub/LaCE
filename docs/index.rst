LaCE documentation
==================

LaCE provides cosmology, simulation-archive, and emulator tools for the
one-dimensional Lyman-alpha forest flux power spectrum. It is used by cup1d
and ForestFlow and can also be used independently for archive inspection and
emulator predictions.
